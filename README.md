## 存放规则

`catalog/` 是阅读目录；`jobs/` 保存实际结果；`batches/` 和 `collections/` 保存旧批次记录；`progress/` 是未完成检查点。源音频另在 Releases 或本地，不在本分支。核验合并成功后只保留合并结果，分段去重信息保存在 `retired-parts.json`。
