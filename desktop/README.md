# Windows 下载器

此目录是已安装应用的源码副本。`transcriber.py` 与 `audio_export.py` 必须放在同一目录。
`media_download.py` 也必须放在同一目录；它提供本地视频下载和可选登录支持。
现有虚拟环境依赖不变，仍使用 PyAV（av）、yt-dlp、faster-whisper。

右上角「转录文字（默认）」可切到「仅下载音频」。同一个转录范围选择器控制
下载全部/下载片段。源音频仍缓存，导出文件名使用视频标题。
不超过 30 MB 的完整导出保留源格式，部分导出为 AAC/M4A，时间戳从零开始。
默认不拆分。仅下载时勾选「自动拆分音频（仅下载，每份不超过 30 MB）」才会检查大小。
超过 30,000,000 字节（30 MB）则以最多 30 分钟
分成独立可播放的 AAC/M4A；如某份仍超限会继续拆小。使用现有 96 kbps 单声道
导出设置，不影响 Whisper 参数。分段文件名含视频标题、顺序及原始时间范围，
上传转录后按顺序合并，原始字幕时间需要加上文件名中的开始时间。
所有分段沿用 7 天保留策略；暂停/失败会删除本轮不完整导出，源缓存不变。
默认输出 `C:\Youtube音频输出` 由安装目录 config.json 配置。
这里不提交本机 config.json、队列、音频或模型。

导出登记在 LOCALAPPDATA/YouTubeTranscriber/audio-exports.json，保留 7 天。
清理仅针对登记且未修改的音频；检查发生在启动与每小时。
已有 TXT/SRT、未登记文件和模型不会被删除。

## 视频和会员登录（仅本机）

右上角选择「下载视频（含声音）」，可选最高720p或1080p；默认优先兼容的MP4，
无兼容MP4时保存MKV。用现有PyAV无损合并，不增加ffmpeg命令依赖，不加载Whisper。
视频目前只支持完整下载，自定义时间段会提示而不是悄悄忽略。视频不登记7天清理，
长期保留直到用户手动删除。临时画面/音轨和Cookie副本在finally中清理。

普通公开视频不需要登录，默认不读取任何浏览器Cookie。
会员内容需要你当前账号拥有对应频道/等级的观看权限，不支持绕过付费墙或DRM。
勾选「授权使用本机登录状态」后确认风险，选择Chrome/Edge/Firefox，配置名可留空。
只使用你选择的来源，不会偷偷改用其他浏览器。每个任务保存来源选择而非Cookie值；
应用重启后登录任务会暂停，需要点击继续并重新授权。

如果Chrome数据库被锁或Windows加密无法解密，程序会解释原因，不会强行关闭浏览器、
提取系统密钥或绕过保护。可自行关闭浏览器重试，或选择你自行导出的YouTube Cookie文件。
Cookie文件是敏感登录凭据，不要上传聊天、云端或GitHub；源文件不会被修改，临时副本会删除。
使用登录账号下载可能触发限流或账号封禁，不能保证所有会员视频可下载。
没有默认读取Cookie、自动上传会员字幕、全频道抓取或后台永久登录功能。

### YouTube JavaScript / EJS 组件

本地下载需要匹配版本的 yt-dlp-ejs，以及受支持的 JavaScript 运行环境。
使用本应用虚拟环境安装 `-r requirements-download.txt`；「更新下载组件」现在更新
`yt-dlp[default]`，避免只更新主包却遗漏配套EJS脚本。不改变转录依赖。
优先使用应用目录 `runtime/node.exe`（Node 22或更新版本），否则查找PATH中的node。
本机安装已配置应用独立Node 24.19.0，不依赖Codex进程或其临时PATH。
只使用本地安装的EJS脚本，不自动启用远程脚本下载，不关闭TLS校验。
安全处理后的下载警告会显示在GUI中；不再隐藏「验证失败，只剩预览图片」等关键信息。
